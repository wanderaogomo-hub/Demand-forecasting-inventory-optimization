# Demand Forecasting & Inventory Optimization

An end-to-end supply chain analytics project using Python to forecast demand and translate forecasts into inventory replenishment decisions.

## Project Objectives

This project answers six key supply chain questions:

- What will future demand look like?
- Which forecasting model performs best?
- When should inventory be reordered?
- How much should be ordered?
- Which warehouses and SKU positions require priority replenishment?
- What are the financial implications of stockout risk and excess inventory?

- Statsmodels

## Project Structure

- `Data/` — source datasets
- `Images/` — analytical visualizations
- `Outputs/` — forecasting and inventory optimization outputs
- `Demand_Forecasting_Inventory_Optimization.ipynb` — complete analysis
- `requirements.txt` — Python dependencies

## Analytical Workflow

Demand Analysis → Forecasting → Model Evaluation → Safety Stock → Reorder Point → Recommended Order Quantity → Warehouse Prioritization → Financial Risk → Excess Inventory → Management Recommendations

## Forecasting Models

The project evaluates:

- Moving Average
- Exponential Smoothing
- ARIMA

Model performance is compared using MAE, RMSE and MAPE.

## Inventory Optimization

Forecasting results are translated into actionable supply chain metrics including:

- Safety stock
- Reorder point
- Days of inventory cover
- Recommended order quantity
- Replenishment priority
- Potential lost revenue
- Potential gross profit at risk
- Excess inventory
- Working capital exposure
